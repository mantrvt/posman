# Posman

Minimalist peer-to-peer sharing in the browser. No login, no server storage.

- Share **files** (chunked, multi-file, download all as ZIP)
- Share **text** (paste, send, one-click copy on the other side)
- Connect with a 6-digit code or QR code (WebRTC via PeerJS)

## Run

```
npm install
npm run dev
```

Theme variables live at the top of `src/index.css` (`:root`).
